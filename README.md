# Interactive Telangana SCERT Learning Platform — Class 8

> **Premium 3D Interactive Educational Web Application for Class 8 English Medium**  
> **State Council of Educational Research and Training (SCERT), Telangana**

---

## 🌟 Overview

The **Interactive Telangana SCERT Learning Platform** is a state-of-the-art educational application designed specifically for Class 8 English Medium students across Telangana. Built with cutting-edge web technologies, it features real-time 3D WebGL visualizations, synchronized paragraph-wise learning, comprehensive Bloom's taxonomy evaluations, and offline Progressive Web App (PWA) support.

## 🚀 Key Features

### 1. 🔮 Magic 3D Opening Screen
- Interactive 3D opening book with page turn depth and golden light beam.
- Orbiting subject glyphs representing Physics, Chemistry, Biology, Mathematics, and Geography.
- Dynamic particles with ambient sound synthesis.

### 2. 🌌 Dynamic 3D Wallpaper & Shifting Themes
- WebGL background running on Three.js with mouse parallax responsive to user cursor movements.
- Automatic theme transitions per subject:
  - **Social Studies**: Earth sphere & celestial coordinates grid.
  - **Physical Sciences**: Atomic nucleus with orbiting electrons.
  - **Biology**: Double-helix DNA strand and cellular floating particles.
  - **Mathematics**: Geometric polyhedra (Icosahedron, Dodecahedron).
  - **Science**: Molecular lattice networks.
  - **English**: Floating alphabet runes and glowing typographic constellations.

### 3. 🔬 Dedicated 3D Learning Visualizer (20+ Interactive Scenes)
- **Interactive Projections**: Mercator cylindrical projection unwrapping vs. 3D Globe.
- **Force & Vectors**: Real-time push/pull force vectors with resultant arrows.
- **Friction Microscopy**: Zooming into micro-asperities (surface roughness interlocking).
- **Cell Biology**: 3D plant & animal cell models with clickable nucleus, mitochondria, and cell wall.
- **Optics & Light**: Planar and concave mirror angle-of-reflection simulations.
- **Geometry & Polyhedra**: Interactive Euler’s formula vertex-edge-face counter.

### 4. 📖 Paragraph-Wise Dual Learning Engine
- **Textbook Idea**: The authentic textbook concept.
- **Easy Explanation**: 2–4 line plain English clarification right beneath.
- **Interactive Concept Links**: Underlined terms trigger animated 3D modal cards with definitions, formula boxes, and real-life connections.

### 5. 🔄 5-Step Mastery Cycle
1. **READ**: Textbook ideas, easy breakdown, key takeaways.
2. **WATCH**: Interactive 3D visual simulations and dynamic demonstrations.
3. **EXPLORE**: Real-life applications, "Did You Know?" fun facts, and "Remember" highlights.
4. **PRACTICE**: Bloom's Taxonomy questions (Remember, Understand, Apply, Analyze, Evaluate, Create) and interactive flashcards.
5. **REVISE**: 5-point summaries, vocabulary glossaries, and Compare & Connect tables.

### 6. 🏆 Chapter Final Exam & Official Printable Certificate
- **20-Question Comprehensive Assessment**: Mixed multiple choice questions covering all topics.
- **Instant Detailed Analytics**: Percentage score, time spent, and question-by-question mistake review with textbook explanations.
- **Telangana SCERT Class 8 Learning Certificate**: Automatically unlocked for scores of **80% or higher**, complete with student name, date, chapter title, percentage, and official seal. Supports one-click high-resolution A4 landscape printing or PDF export.

### 7. 🔊 Procedural Web Audio API Synthesizer
- 100% offline audio generation using browser oscillators:
  - Subtle UI hover ticks
  - Crisp modal opening chimes
  - Correct answer success harmonizers
  - Incorrect answer soft buzz
  - Fanfare triumph melody on certificate unlocks
- Zero external MP3 downloads required.

### 8. ⚡ 100% Offline Progressive Web App (PWA)
- No Node.js or Python server required!
- Can be launched directly via `file:///` protocol or offline PWA.
- Includes `manifest.json` and `service-worker.js`.

## 💻 How to Run

### Method 1: Single-Click Launcher (Windows)
Double-click `Launch_Platform.bat` in the root folder. It will instantly launch the application in your default web browser.

### Method 2: Direct File Open
Simply double-click `index.html` or drag it into any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari, etc.).

### Method 3: PWA Installation
1. Open the platform in Chrome or Edge.
2. Click the **Install** icon in the address bar or select **Install App** from the browser menu.
3. The platform will run as a standalone desktop application with offline caching.
